Core Capabilities

Everything your AI needs to master CodeChef

📊

Deep Profile Analytics

Structured stars, division, global/country rank, rating history with per-contest deltas (get_rating_history), and heat-map activity aggregation (get_activity).

🏆

Contest Ingestion & Tracking

Load a full contest catalog with open_contest, enumerate problems, and persist solving state across sessions via get_contest_progress.

🔒

Isolated Docker Sandbox

run_code executes C++, Python, Java, Go, and Rust inside a network-disabled container with strict CPU and memory ceilings before anything is submitted.

🤖

Automated Submission & Verdicts

Playwright-driven submit_solution posts to CodeChef and polls judge verdicts (AC, WA, TLE, RE) through get_submission_status.

🔧

Self-Repair Retry Engine

On failure, retry_solution diagnoses the verdict, proposes a targeted fix, and re-runs the validate → execute → submit loop autonomously.

🧪

Complexity & Test Synthesis

Estimate time/space complexity with validate_complexity and synthesize adversarial edge-case inputs using generate_tests.

System Design

Dual-Runtime Execution Architecture

Node.js / stdio Lightweight & Zero-Config

An ESM McpServer built on the official MCP SDK with Zod schema validation and Cheerio HTML parsing. Spawned directly by your desktop client — no Docker or Python required.

  • ✓ 11 profile & contest tools
  • ✓ Request caching & rate throttling
  • ✓ Node >= 20, instant npx startup
Python FastMCP Full Autonomous Stack

A FastMCP server exposing all 18 tools over stdio or Streamable HTTP/SSE, backed by SQLAlchemy state, a Docker sandbox runner, Playwright automation, and a diagnostic retry engine.

  • ✓ Isolated container execution
  • ✓ Persistent contest & submission state
  • ✓ Autonomous verdict-driven self-repair
